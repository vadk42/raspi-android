# Как создать своё расписание для Raspi

Приложение берёт расписание из обычного файла `schedule.json` на GitHub. Создать его можно прямо в браузере,
ничего устанавливать не нужно. Займёт минут десять.

## Шаг 1. Создайте свой репозиторий

Самый простой способ: откройте шаблон [raspi-schedule-template](https://github.com/vadk42/raspi-schedule-template)
и нажмите зелёную кнопку **Use this template → Create a new repository**.
Назовите репозиторий, например, `my-schedule`.

Важно: репозиторий должен быть **Public**. Приложение читает файл по ссылке без входа в аккаунт, из закрытого репозитория оно его не получит.

Без шаблона: **New repository**, галочка Public, затем **Add file → Create new file**, имя файла `schedule.json`.

## Шаг 2. Впишите свои пары

Откройте `schedule.json` и нажмите карандаш (**Edit this file**). Структура такая:

```json
{
  "week1Start": "2026-09-01",
  "semesterStart": "2026-09-01",
  "sessionStart": "2026-12-28",
  "days": [
    {
      "day": "Понедельник",
      "lessons": [
        { "title": "Алгоритмы", "start": "08:45", "end": "10:20", "teacher": "Иванов И.И.", "room": "П-13", "type": "lecture" },
        { "title": "Линал", "start": "10:30", "end": "12:05", "teacher": "Петров П.П.", "room": "615", "type": "seminar", "week": "odd" }
      ]
    },
    { "day": "Вторник", "lessons": [] }
  ]
}
```

| Поле | Что писать |
|---|---|
| `week1Start` | Понедельник первой недели семестра в виде `гггг-мм-дд`. От него считаются чётные и нечётные недели |
| `semesterStart`, `sessionStart` | Начало семестра и начало сессии. Нужны для карточки «Прогресс», можно не указывать |
| `day` | `Понедельник`, `Вторник`, `Среда`, `Четверг`, `Пятница`, `Суббота` (воскресенья нет) |
| `title` | Название пары |
| `start`, `end` | Время начала и конца в виде `ЧЧ:ММ`, с ведущим нулём: `08:45`, а не `8:45` |
| `teacher`, `room` | Преподаватель и аудитория. Можно не указывать |
| `type` | `lecture` (лекция) или `seminar` (семинар). Можно не указывать |
| `week` | `odd`: пара только по нечётным неделям, `even`: только по чётным. Без этого поля пара идёт каждую неделю. Не обязательно|

Пары в дне пишите по порядку. День без пар: `"lessons": []`.

Когда закончите, нажмите **Commit changes** (зелёная кнопка), затем ещё раз **Commit changes**.

## Шаг 3. Получите ссылку на файл

1. Откройте `schedule.json` в репозитории.
2. Нажмите кнопку **Raw** справа над текстом файла.
3. Скопируйте адрес из строки браузера. Он выглядит примерно так:
   `https://raw.githubusercontent.com/ваш-ник/навзание-репозитория/main/schedule.json`

## Шаг 4. Вставьте ссылку в приложение

- При первом запуске на шаге «Ссылка на расписание» нажмите **Вставить**, затем **Проверить и загрузить**. Должно появиться «Расписание загружено и подключено».
- Позже: Настройки → Расписание.

## Как менять расписание потом

Откройте файл на GitHub, нажмите карандаш, поправьте, **Commit changes**. В приложении потяните главный экран вниз
или просто откройте его заново. Расписание обновляется не мгновенно: GitHub кэширует файл до нескольких минут.
Если что-то изменилось, в приложении сверху появится кнопка с изменениями.

## Если не получается

| Ошибка | Что проверить |
|---|---|
| «Ошибка 404» или файл не найден | Репозиторий должен быть Public. Проверьте ник, название репозитория, ветку (`main`) и имя файла `schedule.json` |
| Расписание не загружается | Скорее всего, ошибка в JSON: лишняя или пропущенная запятая, незакрытая скобка или кавычка. Вставьте файл на [jsonlint.com](https://jsonlint.com) и исправьте |
| Пара не показывается | Проверьте написание дня (`Понедельник` с заглавной) и время (`08:45`, с нулём) |
| Чётные и нечётные недели перепутаны | Поменяйте `week1Start` или в настройках приложения переключатель сдвига недели |
| Изменения не видны | Подождите несколько минут и потяните экран вниз |
