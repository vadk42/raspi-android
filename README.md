## Возможности

- Расписание на неделю с учётом чётных и нечётных недель, подсветка текущей пары и таймер до её конца
- Прошедшие пары сворачиваются в одну плашку; после последней пары показывается прогресс недели и семестра
- Заметки к парам, раздел «Что изменилось», мероприятия
- Live Updates: плашка с текущей парой в статус-баре (Android 16)
- Свои заставки: фото и видео на фоне, обрезка видео, плавный стык повтора, настройка матовости и прозрачности плашек
- Темы, светлый и тёмный режим, вид плиток, цвета лекций и семинаров
- Обновление приложения изнутри

## Установка

1. Откройте [Releases](../../releases) и скачайте последний `.apk`.
2. Разрешите установку из этого источника и установите.
3. При первом запуске вставьте ссылку на файл с расписанием (формат ниже).


## Свой файл расписания

Пошаговая инструкция: [docs/schedule-guide.md]([main/schedule-guide.md]). Коротко:

Расписание берётся из JSON-файла по ссылке. Пример лежит в [`docs/schedule.example.json`](https://github.com/vadk42/raspi-android/blob/main/schedule-guide.md).
Ссылка должна вести на «сырой» файл, например `https://raw.githubusercontent.com/<имя>/<репозиторий>/main/schedule.json`.

| Поле | Что значит |
|---|---|
| `week1Start` | Понедельник первой недели (`гггг-мм-дд`): от него считаются чётные и нечётные недели |
| `semesterStart`, `sessionStart` | Начало семестра и начало сессии, для карточки «Прогресс» (необязательно) |
| `days[].day` | `Понедельник` … `Суббота` |
| `lessons[].title`, `start`, `end` | Название и время (`ЧЧ:ММ`) |
| `teacher`, `room` | Преподаватель и аудитория (необязательно) |
| `type` | `lecture` или `seminar` (необязательно) |
| `week` | `odd` или `even`: пара только по нечётным или чётным неделям (необязательно) |
| `badge` | Короткая пометка, например «Контрольная» (необязательно) |

## Сборка из исходников

1. Установите Android Studio и откройте папку проекта.
2. Дождитесь Gradle Sync (нужен интернет).
3. Запустите конфигурацию `app` на устройстве или в эмуляторе.

Свою ссылку на обновления меняйте в `AppUpdater.kt` (`UPDATE_JSON_URL`), ссылку на расписание по умолчанию в `ScheduleRepository.kt` (`DEFAULT_URL`).

## Структура

- `app/src/main/java/com/schedule/raspi/` — код приложения (Jetpack Compose)
- `app/src/main/res/` — ресурсы, шрифты
- `app/src/main/assets/fonts/` — необязательный `display.ttf` для шрифта заголовков
